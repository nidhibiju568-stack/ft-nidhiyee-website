FT.NIDHIYEEE 0.2 — WEBSITE FILES
================================

FILES
- index.html: page content and links
- style.css: colors, layout, mobile responsive design
- script.js: category filters and mobile navigation

PREVIEW
Open index.html in a browser. Internet is only needed to load the optional Google Fonts.

BEFORE PUBLISHING
1. Open index.html in any text editor.
2. Find the comment "Replace this URL with your new channel's exact YouTube link when ready."
3. Replace https://www.youtube.com/ in the Subscribe button with the exact URL for your new FT.NIDHIYEEE 0.2 channel.
4. The main-channel links currently point to https://www.youtube.com/@Yesitsnidhi. Change them if your main channel URL differs.

PUBLISH FREE (GitHub Pages)
1. Sign in to GitHub and create a new public repository, for example: ftnidhiyee-site.
2. Upload index.html, style.css, and script.js to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose "Deploy from a branch", select the main branch and /(root), then Save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.
Note: GitHub's interface may change. You can also use a static website host such as Netlify by uploading the project files.

CUSTOMIZATION
- Edit text and links in index.html.
- Change colors near the top of style.css: --bg, --red, --text.
- The gallery cards are category cards, not actual video embeds yet. Add your own video links when ready.
